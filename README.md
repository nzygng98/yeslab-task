# YesLab 新成员任务一：Ubuntu 与 ROS 环境搭建

## 一、环境信息
*   Ubuntu 版本：20.04.6 LTS
*   ROS 版本：Noetic
*   虚拟机软件：VirtualBox 7.2.18

## 二、安装过程与遇到的问题
### 1. 虚拟机软件选择
最初尝试下载 VMware，但博通官网注册流程繁琐，收不到验证码，无法下载。为了不耽误进度，果断改用开源免费的 VirtualBox 虚拟机。

### 2. 安装向导按钮被遮挡
在安装 Ubuntu 时，安装窗口尺寸过大，底部的“继续”按钮被挤出屏幕，鼠标无法点击。尝试拖动窗口和键盘盲操均无效。**解决办法**：将安装界面语言切换为英文，由于英文字符较短，界面自动收缩，按钮成功露出并点击。

### 3. ROS 安装与配置报错
手打 ROS 密钥和环境变量配置命令时，因为漏打空格，导致 `echo` 和 `source` 连在一起，报出 `No such file or directory` 错误。**解决办法**：利用 `sed -i '/echosource/d' ~/.bashrc` 清理了错误配置，重新正确写入环境变量，最终验证成功。
